Stronger compression converts each page into a compressed image. The output will no longer have selectable/searchable text and may lose links, bookmarks, forms, and accessibility features. Choose Basic optimization if those matter.
Basic optimization re-saves the PDF and may reduce file size, but the result depends on how the original was created. It does not aggressively recompress embedded images.
