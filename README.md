# PDF Toolkit · StudyMats

Client-side PDF toolkit with **bookmark-based chapter extraction**.

Part of the [StudyMats](https://mdfl212.github.io/mdfl212.studymats.io/) toolkit by [mdfl212](https://github.com/mdfl212).

## Live demo

**https://mdfl212.github.io/pdf-toolkit/**

(Direct file: [pdf-toolkit.html](https://mdfl212.github.io/pdf-toolkit/pdf-toolkit.html))

## Features

- **Chapter Extractor** — read PDF bookmarks, calculate hierarchy-aware page ranges, extract chapters to individual PDFs or a ZIP
- Merge, Split, Delete pages, Rotate, Reorder, Watermark, Metadata
- 100% client-side (pdf-lib + PDF.js + JSZip)
- Dark mode with CSU green + gold accents
- PWA: installable + offline when served over HTTPS

## Local use

Open `pdf-toolkit.html` in a browser, or serve the folder:

```bash
npx serve .
```
